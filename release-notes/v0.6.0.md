# v0.6.0

## Authenticated Team Dashboard

Extends `0dai serve` with session-based authentication and multi-page navigation.

### Authentication

```bash
# Simple password auth
0dai serve --target /path --auth --password mypassword

# Multi-user from JSON file
0dai serve --target /path --auth --users users.json

# Via environment variable
ODAI_DASHBOARD_PASSWORD=secret 0dai serve --target /path --auth
```

Users file format (`users.json`):
```json
{
  "alice": "<sha256-hex-of-password>",
  "bob": "<sha256-hex-of-password>"
}
```

### Pages

| Page | Path | Content |
|------|------|---------|
| Overview | `/` | Health, manifests, codebase, personas, bulletins, policy |
| Activity | `/activity` | Audit log — who did what, when (last 50 entries) |
| WAL | `/wal` | Write-ahead log — MCP mutations with undo status |

### Security

- SHA-256 password hashing (no plaintext storage)
- Session cookies: HTTP-only, SameSite=Strict, 8-hour TTL
- Login page with invalid credentials feedback
- Auth status badge in navigation bar

### API

`/api/health` remains unauthenticated for monitoring integration.
