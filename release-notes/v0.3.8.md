# v0.3.8

## Remote MCP Server (Streamable HTTP)

Run the 0dai MCP server over HTTP for remote access — team setups, CI/CD, and web dashboards.

### Usage

```bash
# Start HTTP server (default: 127.0.0.1:8421)
0dai mcp --target /path --http

# Custom host and port
0dai mcp --target /path --http --host 0.0.0.0 --port 9000

# stdio mode unchanged (default)
0dai mcp --target /path
```

### Connecting

Add to `.mcp.json` in any project to connect to a remote 0dai server:

```json
{
  "mcpServers": {
    "0dai-remote": {
      "type": "streamable-http",
      "url": "http://127.0.0.1:8421/mcp"
    }
  }
}
```

### Use Cases

- **Team server** — one MCP server for the whole team, shared manifests
- **CI/CD** — query AI layer state from build pipelines
- **Web dashboard** — connect `0dai serve` to remote MCP data
- **Multi-repo** — one server aggregating knowledge from multiple repos

### Security

- Default host `127.0.0.1` (localhost only) — safe by default
- Use `--host 0.0.0.0` only in trusted networks or behind a reverse proxy
- No authentication built-in — rely on network-level security (VPN, firewall)
- All 22 MCP tools available in both stdio and HTTP modes
