# v0.2.1

## 0dai MCP Server

0dai is now an MCP server. Any MCP-compatible agent (Claude Code, Cursor, Windsurf, etc.) can query the project's AI layer directly through the Model Context Protocol.

### 11 Tools

| Tool | Purpose |
|------|---------|
| `get_project_health` | Full health check — start here |
| `get_project_manifest` | Stack, agents, commands, paths |
| `get_codebase_map` | Entry points, deps, dir roles, file types, repo mode |
| `get_org_policy` | Active permissions, MCP restrictions, hooks, constraints |
| `get_commands` | Command tier classification (safe/workspace/ops) |
| `get_environment` | Runtime context, available CLIs |
| `get_discovery` | Detected stack and native configs |
| `get_applied_lock` | Installed pack versions and checksums |
| `get_ai_version` | AI layer and schema version |
| `search_experience` | Search knowledge base for patterns and lessons |

### Usage

```bash
# Start MCP server (stdio)
0dai mcp --target /path/to/project

# Or via .mcp.json (auto-configured)
{
  "mcpServers": {
    "0dai": {
      "command": "python3",
      "args": ["scripts/mcp_server.py", "--target", "."]
    }
  }
}
```

### Architecture

- Built on FastMCP 3.1.1 (24K stars, powers 70% of MCP servers)
- Read-only by design — agents query knowledge, cannot mutate state
- Works as standalone stdio server or in-process tool in Claude Agent SDK
- No CLI wrapping — knowledge served via protocol, not subprocess
