# v0.1.7

This release makes the 0dai product name the default command-line experience.

## Highlights

- `0dai` is now the primary user-facing command.
- `0dai-repo` and `0dai-task` remain available as explicit aliases.
- Legacy `ai-repo` and `ai-task` still work as compatibility shims.
- Logs, workflow artifact names, and runtime entrypoints now follow the `0dai` prefix more consistently.

## Major Changes

- primary CLI renamed to `0dai`
- prefixed runtime and report names cleaned up
- docs and tests aligned with the new default UX

## Validation

- `python3 scripts/validate_templates.py`
- `bash tests/smoke_test.sh`
