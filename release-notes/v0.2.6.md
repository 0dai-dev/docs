# v0.2.6

## Python SDK

Programmatic access to the ai/ operating layer — zero dependencies, pure Python 3.10+.

### Installation

```bash
cd sdk && pip install .
```

### API

```python
import zerodayai

# Check AI layer version
zerodayai.version("/path/to/project")
# → {"version": "0.2.6", "schema_version": "1"}

# Full health check
h = zerodayai.health("/path/to/project")
# → {"ai_layer_installed": True, "stack": "fastapi", "repo_mode": "polyrepo", ...}

# Detect project stack
zerodayai.detect("/path/to/project")
# → {"stack": "fastapi", "native_configs": [...]}

# Get codebase structural map
zerodayai.codebase_map("/path/to/project")
# → {"repo_mode": "polyrepo", "entry_points": [...], "dependency_managers": {...}}

# Get all manifests at once
zerodayai.manifests("/path/to/project")
# → {"project": "...", "discovery": {...}, "commands": "...", ...}

# Search experience knowledge base
zerodayai.experience("/path/to/project", query="bugfix")
# → {"query": "bugfix", "matches": 3, "results": [...]}

# Summarize experience
zerodayai.experience("/path/to/project")
# → {"events": 12, "candidates": 3, "accepted": 1}
```

### Use Cases

- **CI/CD integration**: check `health()` in pipelines, fail on missing manifests
- **Custom tooling**: build project dashboards reading `manifests()` and `codebase_map()`
- **Experience analytics**: aggregate `experience()` across multiple repos
- **Multi-repo scripts**: iterate projects, call `detect()` to route logic by stack
