# v0.1.6

This release turns the 0dai knowledge loop into a more complete operational workflow.

## Highlights

- `ai-task run` now provides a standard local wrapper for recording normalized task events into `ai/experience/outbox`.
- `scripts/aggregate_experience.py` now summarizes experience data into a CI-friendly report and GitHub Actions uploads it as an artifact.
- Timestamp handling in `ai-task` is now timezone-aware and warning-free.

## Major Changes

- standard local event wrapper via `ai-task`
- CI aggregation and artifact upload for experience reports
- cleaner event timestamp handling

## Validation

- `python3 scripts/validate_templates.py`
- `bash tests/smoke_test.sh`
