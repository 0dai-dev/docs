# v0.4.2

## Pre-Release Auditor

Automated release readiness gate — run `0dai audit` before tagging.

### Commands

```bash
# Full audit report
0dai audit

# JSON for CI pipelines
0dai audit --json

# Show fix suggestions for failures
0dai audit --fix
```

### Checks Performed (13 total)

| Category | What It Checks |
|----------|---------------|
| Version | VERSION matches CHANGELOG, release-notes, bootstrap, SDK |
| Git | Working tree clean, on main branch |
| Templates | validate_templates.py passes |
| Guardian | roadmap_guardian.py passes (stacks, docs, smoke coverage) |
| Migrations | Direct migration path exists for current version |
| Smoke | smoke_test.sh exists and references current version |
| Changelog | Current version has bullet entries |

### Exit Codes

- `0` — audit=PASS, ready for release
- `1` — audit=FAIL, blocking issues found

### CI Integration

```yaml
- name: Pre-release audit
  run: python3 scripts/release_auditor.py --json
```
