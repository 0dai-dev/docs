# v0.4.4

## Stack Compatibility Tester

Automated validation of all 9 project layouts — scaffold, verify, report.

### Commands

```bash
# Test all stacks
0dai stack-test

# Test one stack
0dai stack-test --stack fastapi

# JSON for CI
0dai stack-test --json
```

### What It Tests

For each of the 9 stacks (backend-api, data-ml, fastapi, flutter, fullstack-monorepo, go-service, nextjs, python-service, react-native):

1. `scaffold.sh` and `structure.md` exist in project_layouts/
2. `init-new` completes without errors
3. AI layer files created: VERSION, project.yaml, commands.yaml, discovery.json, applied-lock.json
4. Native configs created: .claude/settings.json, .claude/CLAUDE.md, AGENTS.md
5. All paths from structure.md exist in scaffolded output
