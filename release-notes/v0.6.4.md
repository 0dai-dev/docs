# v0.6.4

## Concurrent Edit Resolution

Detect and resolve ai/ layer conflicts across branches before merge.

### Commands

```bash
# Detect conflicts against main
0dai conflicts --target /path --branch main

# Auto-resolve managed files
0dai conflicts --target /path --branch main --resolve

# JSON output
0dai conflicts --target /path --branch main --json
```

### How It Works

1. Finds merge-base between current branch and target
2. Compares files changed in both branches since merge-base
3. Managed files (marked `managed: true`) auto-resolved: upstream version wins
4. Custom files flagged for manual review

### MCP Tool

`check_conflicts` returns conflict list with resolution strategy (35 MCP tools total).
