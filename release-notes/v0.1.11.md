# v0.1.11

This release makes 0dai more aware of where it is running, not just what repository it is attached to.

## Highlights

- `ai/manifest/environment.yaml` is now generated as part of bootstrap and sync.
- Execution context now captures environment kind, execution mode, available CLIs, capabilities, and constraints.
- An `ops_dashboard` detector and richer command/path heuristics improve behavior on operational repositories discovered during dogfooding.

## Major Changes

- environment manifest generation
- execution-context modeling in the canonical AI layer
- dogfood-driven detector and command heuristics improvements

## Validation

- `python3 scripts/validate_templates.py`
- `bash tests/smoke_test.sh`
