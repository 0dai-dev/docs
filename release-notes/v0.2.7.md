# v0.2.7

## Web Dashboard

`0dai serve` launches a read-only web dashboard for the project AI layer.

```bash
0dai serve --target /path/to/project --port 8420
# → http://127.0.0.1:8420
```

### What It Shows

- **Health**: AI layer version, manifest presence (N/5), org policy status, experience counts
- **Codebase**: entry points, dependency managers, file counts, language distribution
- **Personas**: installed agent personas (architect, qa, devops, security)
- **Bulletins**: active knowledge bulletins with severity badges
- **Command Tiers**: safe/workspace/ops command distribution
- **Org Policy**: applied packs and protected path counts

### API

```bash
curl http://127.0.0.1:8420/api/health
# → {"version": "0.2.7", "installed": true}
```

### Design

- Dark theme, responsive grid, mobile-friendly
- Zero dependencies — pure Python stdlib (http.server)
- Read-only — cannot modify project state
- Single HTML page, no JavaScript frameworks
