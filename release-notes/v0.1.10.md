# v0.1.10

This release adds the first GitHub-native issue creation boundary to the 0dai knowledge loop.

## Highlights

- `scripts/create_knowledge_issue.py` can open GitHub issues from prepared intake summaries.
- The CI workflow can now create intake issues when `ODAI_KNOWLEDGE_REPO` is configured.
- The telemetry runtime path now includes dry-run issue creation for safer integration testing.

## Major Changes

- GitHub auto-intake step
- issue creation from `0dai-knowledge-intake.json`
- safer CI/runtime integration guards for knowledge governance

## Validation

- `python3 scripts/validate_templates.py`
- `bash tests/smoke_test.sh`
