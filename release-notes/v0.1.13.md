# v0.1.13

## New Stack Layouts

Three new first-class stack layouts join the existing five:

- **go-service**: Standard Go project layout with `cmd/server/`, `internal/`, `pkg/`, and `migrations/`.
- **fastapi**: Python FastAPI service with `app/api/routes/`, `app/models/`, `app/schemas/`, and `app/services/`.
- **data-ml**: Data science and ML workspace with `notebooks/`, `src/pipelines/`, `data/`, and `configs/`.

## Stack Detection

New detector YAML files allow `0dai detect` and `0dai init-existing` to recognize Go, FastAPI, and data/ML projects automatically.

## Validation

Smoke test coverage extended to verify scaffolding, manifest generation, and directory structure for all new stacks.
