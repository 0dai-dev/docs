# v0.2.8

## Enterprise Audit Logging

Every 0dai operation now logs to `ai/manifest/audit.jsonl`:

```jsonl
{"timestamp":"2026-03-28T...","action":"sync","actor":"cli","user":"dev","ai_version":"0.2.8","details":"stack=fastapi agents=codex,claude,opencode"}
{"timestamp":"2026-03-28T...","action":"init-existing","actor":"cli","user":"dev","ai_version":"0.2.8","details":"stack=node agents=codex,claude,opencode"}
```

Tracked actions: `init-existing`, `sync` (more coming).
MCP tool `get_audit_log` returns most recent entries.

## Semantic Search (TF-IDF)

Experience search now uses TF-IDF relevance ranking instead of substring matching:

```bash
0dai search --target /path --query "auth token refresh"
```

Results are scored by term frequency / inverse document frequency:
```json
{
  "query": "auth token refresh",
  "indexed_documents": 47,
  "matches": 5,
  "results": [
    {"path": "ai/experience/accepted/skills/...", "score": 0.1847, ...},
    {"path": "ai/experience/events/...", "score": 0.0923, ...}
  ]
}
```

MCP `search_experience` tool upgraded to same TF-IDF engine.
Zero external dependencies — pure Python stdlib math.
