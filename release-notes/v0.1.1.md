# v0.1.1

This release turns ZeroDayAI into a much stronger AI operating layer for real repositories.

## Highlights

- `ai/` is now the canonical generation and sync layer, while native tool files are emitted where Codex, Claude Code, and OpenCode actually read them.
- Bootstrap now writes manifest-driven outputs in `ai/manifest/` so project shape, commands, selected tools, and protected paths have one source of truth.
- Claude Code support is expanded with native `.claude/CLAUDE.md`, `.claude/rules/`, `.claude/hooks/`, and `.claude/agents/` outputs.
- Existing `AGENTS.md` and `.claude/CLAUDE.md` are preserved through managed block merging for safer adoption in live repositories.
- Sync is now version-aware through `ai/VERSION` and explicit migration scripts.

## Major Changes

- Canonical/native bootstrap architecture
- Managed block integration for existing instruction entrypoints
- Richer manifest generation with package manager, monorepo structure, paths, and protected paths
- Migration-aware sync with `bootstrap/migrations/0.1.0_to_0.1.1.sh`

## Validation

- `python3 scripts/validate_templates.py`
- `bash tests/smoke_test.sh`

## Upgrade Note

Projects with an existing `ai/VERSION` can now be upgraded through `./bin/ai-repo sync --target <path>` using version-aware migration handling.
