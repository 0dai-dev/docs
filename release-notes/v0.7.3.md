# v0.7.3

## Session Roaming

Start a task in Claude Code. Continue in Codex. Finish in Gemini. Session context transfers seamlessly.

### The Problem

You're debugging in Claude Code, realize you need a quick mechanical edit better suited for Codex. You switch — and lose all context. What files you touched, what you decided, what's left to do. You start over.

### The Solution

```bash
# Save session before switching agents
0dai session --target . save --summary "Auth middleware done, need to wire routes"

# In the other agent — context is already there
# (SessionStart hook auto-shows handoff notes)

# Or check manually
0dai session --target . status

# When done
0dai session --target . complete
```

### What Gets Transferred

| Field | Description |
|-------|-------------|
| `goal` | What you're trying to accomplish |
| `plan` | Steps with completion tracking |
| `files_touched` | Recently modified files (from git) |
| `key_decisions` | Decisions made during the session |
| `handoff_notes` | Free-text context for the next agent |
| `history` | Which agents worked on this, when |

### How Agents Pick Up Sessions

1. **SessionStart hook** — automatically prints active session details when any agent starts
2. **MCP tool `get_session`** — agents can query session programmatically
3. **MCP tool `save_session`** — agents update session before handoff

### Storage

```
ai/sessions/
  active.json          ← current session
  archive/
    sess-1711700000.json  ← completed sessions
```

### CLI

| Command | What it does |
|---------|-------------|
| `session save --summary "..."` | Save/update session |
| `session status` | Show active session |
| `session complete` | Archive and clear |
| `session history` | List past sessions |
| `session --json` | JSON output |

### MCP Tools

- `get_session` — read active session (38 MCP tools total)
- `save_session` — update session with handoff notes
