# v0.5.5

## Prompt Versioning

Track and diff system prompt changes over time across all agent CLIs.

### Commands

```bash
# Take snapshot of current prompt state
0dai prompt-history --target /path

# Check what changed since last snapshot
0dai prompt-history --target /path --status

# View snapshot history
0dai prompt-history --target /path --history

# JSON output
0dai prompt-history --target /path --json
```

### Tracked Directories

- `ai/prompts/` — system and task prompts
- `.claude/agents/` — Claude Code agent definitions
- `.gemini/agents/` — Gemini agent definitions
- `.aider/agents/` — Aider agent definitions

### How It Works

1. `prompt-history` snapshots file hashes and versions
2. History stored in `ai/prompts/.history.json` (last 50 snapshots)
3. Each snapshot records: added, modified, removed files
4. `--status` compares current state against last snapshot
5. Detects prompt drift — when managed prompts are manually edited

### MCP Tool

`get_prompt_history` returns current status and change history.
