# v0.2.2

## Bidirectional Experience Loop

Knowledge now flows in both directions between 0dai upstream and projects.

### Project → Upstream: Telemetry Reports

```bash
# Preview what would be reported (nothing leaves the project)
0dai report --dry-run

# Generate anonymized telemetry report
0dai report
```

Reports contain **only aggregated metrics** — no code, no paths, no secrets:
- Event counts, CI pass rate, human takeover rate, revert rate
- Tool usage distribution (claude/codex/opencode)
- Task type distribution (bugfix/feature/refactor)
- Accepted knowledge counts by category
- Applied bulletins list

Project name is SHA256-hashed for anonymity.

### Upstream → Project: Bulletins

```bash
# Pull latest bulletins without full sync
0dai pull-bulletins --target /path

# Bulletins also sync automatically during:
0dai sync --target /path
```

Bulletins contain cross-project learnings:
- Security advisories (e.g., MCP server vulnerabilities)
- Best practice updates (e.g., configurable experience TTL)
- Pattern warnings from aggregated experience

Bulletins auto-expire on their `expires` date.

### MCP Integration

Two new tools for agents:
- `get_bulletins` — read active advisories and best practices
- `get_telemetry_summary` — latest aggregated operational metrics
