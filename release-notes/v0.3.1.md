## Maturity Scorecards

New `0dai maturity` command rates AI layer completeness on a 0-100 scale:

```bash
0dai maturity --target /path/to/project
```

## Memory Bank

New `memory-bank/` directory for persistent project state:
- `current_state.json`, `current_task.json` — live project metrics
- `roadmap.json` — machine-readable roadmap with priority scores
- `backlog.json` — all pending ideas with scores
- `decisions.md` — key architectural decisions
- `skills.json` — reusable workflow definitions
- `agents.json` — subagent role descriptions
