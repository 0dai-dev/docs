# v0.2.3

## Pre-Sync Backup

`0dai sync` now creates a tar.gz backup of `ai/` before applying changes:
- Stored in `ai/.backups/pre-sync-<timestamp>.tar.gz`
- Last 5 backups retained, older ones auto-pruned
- Supports `--dry-run` to preview without backup creation

Restore from backup if sync breaks something:
```bash
tar -xzf ai/.backups/pre-sync-20260328T074800Z.tar.gz -C /path/to/project
```

## Configure Wizard

New `0dai configure` command for one-command project setup:

```bash
# List available presets
0dai configure

# Apply a preset
0dai configure --target /path --preset standard

# Preview before applying
0dai configure --target /path --preset enterprise --dry-run
```

### Presets

| Preset | Agents | MCP | Org Policy | Hooks |
|--------|--------|-----|------------|-------|
| **minimal** | claude | none | none | off |
| **standard** | codex, claude, opencode | filesystem | none | on |
| **enterprise** | codex, claude, opencode | filesystem, github | enterprise-default | on |

Generates `ai/config/project-config.json` and updates `.mcp.json` with recommended servers.
