# v0.3.7

## Backstage Software Template Export

Export 0dai project layouts as Backstage-compatible Software Templates for enterprise developer portals.

### Commands

```bash
# List available layouts
0dai backstage-export --list

# Export all as Backstage templates
0dai backstage-export --export all

# Export specific stack
0dai backstage-export --export fastapi --output ./my-backstage-templates

# JSON metadata
0dai backstage-export --json
```

### Exported Templates

| Stack | Language | Description |
|-------|----------|-------------|
| backend-api | TypeScript | Backend API with services and packages |
| data-ml | Python | Data science with notebooks and pipelines |
| fastapi | Python | FastAPI microservice |
| flutter | Dart | Cross-platform mobile app |
| fullstack-monorepo | TypeScript | Web + API monorepo |
| go-service | Go | Go backend service |
| nextjs | TypeScript | Next.js web application |
| python-service | Python | Python backend service |
| react-native | TypeScript | React Native mobile app |

### Template Structure

Each exported `template.yaml` includes:
- **Project Details** step: name, owner, description
- **AI Layer Configuration** step: agent selection, preset (minimal/standard/enterprise)
- **Scaffold** action: `0dai:init-new` with selected stack
- **Publish** action: push to GitHub
- **Register** action: add to Backstage catalog

### Pre-generated Templates

Available in `backstage/` directory — ready to import into any Backstage instance.
