# v0.5.3

## Aider CLI Support

Aider (50K+ stars) is now the 5th supported agent CLI alongside Codex, Claude Code, OpenCode, and Gemini.

### What's Generated

| File | Purpose |
|------|---------|
| `.aider.conf.yml` | Aider configuration with project context reads |
| `.aider/agents/coder.md` | Default coding agent |
| `.aider/agents/reviewer.md` | Code review agent |
| `.aider/agents/architect.md` | System design agent |
| `.aider/agents/qa.md` | Quality assurance agent |
| `.aider/agents/devops.md` | CI/CD and infrastructure agent |
| `.aider/agents/security.md` | Security review agent |

### How It Works

- Aider detected via `detect_available_clis()` checking for `aider` binary
- Configs generated during `init-existing` and `sync`
- Added to standard and enterprise configure presets
- Agent templates follow the same persona-derived pattern as Claude Code and Gemini

### Aider Features

- **Git-native**: auto-commits with meaningful messages
- **BYOK**: bring your own key — works with any model provider
- **Read context**: `.aider.conf.yml` pre-configures reads for `ai/` layer docs
- **50K+ GitHub stars**: one of the most popular AI coding tools
