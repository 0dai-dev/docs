# v0.1.0

Initial release of `ZeroDayAI`.

## Highlights

- Shared `ai/` operating layer for Codex CLI, Claude Code, and OpenCode.
- Safe bootstrap flows for both existing repositories and greenfield project creation.
- Managed root configs for `.codex/`, `.claude/`, `opencode.json`, `.opencode/agents/`, and `.mcp.json`.
- Stack-aware layouts for `flutter`, `backend-api`, `nextjs`, `python-service`, and `fullstack-monorepo`.
- Upstream smoke test and template validation to protect the bootstrap contract.

## Included Commands

- `./bin/ai-repo detect --target <path>`
- `./bin/ai-repo init-existing --target <path>`
- `./bin/ai-repo init-new --stack <name> --target <path>`
- `./bin/ai-repo sync --target <path>`

## Validation

- `python3 scripts/validate_templates.py`
- `bash tests/smoke_test.sh`
