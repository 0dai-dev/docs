# v0.4.3

## Documentation Drift Detector

Find stale documentation by comparing code state against docs.

### Commands

```bash
0dai doc-drift          # human-readable report
0dai doc-drift --json   # CI-friendly JSON
```

### Checks (41 total)

| Category | What It Checks |
|----------|---------------|
| CLI commands | Every command in `bin/0dai` usage is documented in README |
| Script refs | Every script referenced in `bin/0dai-repo` actually exists |
| Stack docs | Each project layout has both scaffold.sh and structure.md |
| Persona fields | All personas have name, display_name, description, system_prompt |
| Architecture | Core docs (architecture.md, bootstrap-spec.md) exist |
| Agent-persona | Each persona has a matching Claude agent template |

### Output

```
drift=none       # all clear
drift=warnings   # non-critical issues found
drift=detected   # breaking drift found (exit code 1)
```
