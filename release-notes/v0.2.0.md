# v0.2.0

## Production Readiness Release

This release graduates 0dai from the v0.1.x feature-building phase to v0.2.0 with a focus on reliability, error handling, and testing.

### Unit Test Suite

12 automated tests covering the core Python scripts:
- `analyze_codebase.py`: manifest generation, monorepo/polyrepo detection, missing dir handling
- `aggregate_experience.py`: empty experience, event aggregation, malformed JSON handling
- `score_knowledge_intake.py`: scoring algorithm, confidence levels, missing input
- `roadmap_guardian.py`: consistency pass verification
- `validate_templates.py`: template structure validation

Run with: `python3 tests/unit/test_scripts.py`

### JSON Error Handling

All Python scripts now handle malformed JSON gracefully:
- `aggregate_experience.py`: skips bad files with warning instead of crashing
- `score_knowledge_intake.py`: clear error message with file path on parse failure
- `prepare_knowledge_issue.py`: clear error message with file path on parse failure

### Dynamic Experience TTL

Experience candidates now expire based on configurable TTL:
- Default: 180 days from creation
- Override: `ODAI_EXPERIENCE_TTL_DAYS=365` environment variable
- Replaces previously hardcoded date

### Verbose Mode

All bootstrap commands now support `--verbose` / `-v`:
```bash
0dai init-existing --target /path --verbose
0dai sync --target /path -v
```

### v0.2.0 Roadmap

Published roadmap for the v0.2.x series:
- **Now**: Test suite hardening, error handling, sync safety
- **Next**: Config wizard, multi-agent personas, custom stack extensibility
- **Later**: Semantic search, audit logging, cross-repo federation
