# v0.1.8

This release makes the 0dai product name the default command-line experience everywhere it matters.

## Highlights

- `0dai` is now the primary user-facing command.
- `0dai-repo` and `0dai-task` remain available as explicit aliases.
- Legacy `ai-repo` and `ai-task` still work as compatibility shims.
- Logs, runtime entrypoints, workflow artifact names, and CI-facing template names are now aligned with the `0dai` prefix.

## Major Changes

- primary CLI is `0dai`
- cleaned command, log, and artifact prefixes
- docs and smoke tests now assume `0dai` by default

## Validation

- `python3 scripts/validate_templates.py`
- `bash tests/smoke_test.sh`
