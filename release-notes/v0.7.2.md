# v0.7.2

## Compliance Reporting

Generate SOC 2 Type II and ISO 27001:2022 evidence from your ai/ layer.

### Commands

```bash
# SOC 2 report (default)
0dai compliance --target /path

# ISO 27001 report
0dai compliance --target /path --framework iso27001

# JSON output
0dai compliance --target /path --json
```

### Evidence Sources (8)

| Source | What It Proves |
|--------|---------------|
| Audit log | All operations logged with timestamp, user, action |
| WAL | All mutations recorded with rollback capability |
| Role policy | Access restricted by role (viewer/developer/lead/admin) |
| Org policy | Security policies enforced (protected paths, denied commands) |
| Experience pipeline | Knowledge lifecycle managed (capture → review → promote) |
| Version control | Versioned layer with checksums and lock files |
| Prompt versioning | System prompt changes tracked and diffable |
| Licensing | Feature access controlled by license tier |

### Framework Controls

**SOC 2:** CC6.1-6.2 (Access), CC7.2-7.4 (Change Mgmt), CC8.1 (Risk)
**ISO 27001:** A.5.1 (Policies), A.8.3 (Access), A.8.9/A.8.32 (Change), A.8.15 (Logging), A.8.25 (Secure Dev)
