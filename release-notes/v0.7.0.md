## Product Landing Page, Monetization & Positioning

### Landing Page

Run `0dai site` to serve a single-page product site with:
- Problem-first hero: "Stop duplicating AI agent configs 5 different ways"
- Before/After visual: 5 config sets → 1 ai/ directory
- Quick Start in 3 commands
- 4 feature cards (Universal Config, Experience Flywheel, MCP Server, Team KB)
- 3 use case cards (Solo Dev, Team, Enterprise)
- 3-tier pricing (Free / Team $29/mo / Enterprise)
- FAQ (6 questions)
- Catppuccin Mocha dark theme, responsive, zero dependencies

### Monetization Tiers

| Tier | Price | Key Features |
|------|-------|-------------|
| Free | $0 | All core commands, all stacks, all CLIs, experience flywheel, MCP server |
| Team | $29/mo | Shared KB, activity feed, role-based access, federation, conflict resolution |
| Enterprise | Custom | SSO/SAML, compliance reporting, policy engine, SLA |
