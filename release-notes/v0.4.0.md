# v0.4.0

## Changelog Automation

Generate structured CHANGELOG entries from git history — no more manual changelog editing.

### Commands

```bash
# Generate from last tag to HEAD
0dai changelog

# Specific range
0dai changelog --from v0.3.3 --to HEAD

# Set version header
0dai changelog --version 0.4.0

# Prepend directly to CHANGELOG.md
0dai changelog --version 0.4.0 --apply

# JSON output for CI
0dai changelog --json
```

### How It Works

1. Detects latest git tag as starting point (or use `--from`)
2. Reads commits between refs
3. Categorizes by conventional commit prefix: feat/add, fix, refactor, docs, test, ci, chore
4. Falls back to keyword detection (add → Features, fix → Fixes)
5. Groups and formats as markdown
