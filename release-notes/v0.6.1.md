# v0.6.1

## Shared Knowledge Base

Centralized team-level knowledge hub — all projects push and pull accepted experience.

### Commands

```bash
# Connect project to shared KB
0dai kb --target /path init --kb-path /shared/team-kb

# Push accepted knowledge to KB
0dai kb --target /path push

# Pull team knowledge (skips own contributions)
0dai kb --target /path pull

# Show KB status and contributors
0dai kb --target /path status

# Search team knowledge
0dai kb --target /path search "auth timeout"

# JSON output
0dai kb --target /path --json
```

### How It Works

1. `init` creates KB directory structure and connects the project
2. `push` copies accepted rules/skills/playbooks/anti-patterns to KB (prefixed with project name)
3. `pull` downloads team knowledge into `ai/experience/team-knowledge/` (excludes own items)
4. Contributor tracking in `meta/kb.json` — who pushed what, when

### Federation vs Knowledge Base

| Feature | Federation | Knowledge Base |
|---------|-----------|----------------|
| Topology | Peer-to-peer | Hub (centralized) |
| Scope | Specific repo pairs | Entire team |
| Storage | Per-peer in `federated/` | Shared directory |
| Discovery | Manual `--add` | Single `init` |

### MCP Tool

`get_knowledge_base` returns status, items, contributors, and optional search.
