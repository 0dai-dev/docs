# v0.5.2

## Experience Auto-Scoring

Rank experience candidates automatically by impact, frequency, and quality signals.

### Scoring Dimensions

| Dimension | Range | Signal |
|-----------|-------|--------|
| Recurrence | 0-10 | Number of identical observations |
| CI Signal | 0-5 | Pass rate of associated events |
| Stability | 0-3 | No reverts within 7 days |
| Scope Clarity | 0-2 | Specific file paths vs wildcards |
| Review Quality | 0-3 | Human review outcomes |
| Type Weight | 0-2 | Rules/anti-patterns weighted higher |

**Max score: 25**

### Recommendations

- **promote** (>= 18): Strong evidence, auto-promotable
- **review** (>= 10): Worth reviewing, needs human judgment
- **defer** (< 10): Needs more evidence before promotion

### Commands

```bash
# Score all candidates
0dai score-experience --target /path

# JSON output
0dai score-experience --target /path --json

# Auto-promote high-scoring candidates
0dai score-experience --target /path --auto-promote
```

### MCP Tool

`score_candidates` returns all candidates with their scores and recommendations.

### How It Works

1. Reads candidates from `ai/experience/candidates/`
2. Cross-references with events in `ai/experience/events/`
3. Evaluates each candidate across 6 dimensions
4. Returns sorted list with scores and recommendations
5. `--auto-promote` moves candidates scoring >= 18 to `ai/experience/accepted/`
