# v0.3.4

## Agent Teams Config Generator

Generate rich, persona-derived Agent Teams for Claude Code's `.claude/agents/` directory.

### Agents Included

| Agent | Role | Source Persona |
|-------|------|---------------|
| planner | Implementation planning from manifests and playbooks | — |
| reviewer | Architecture, safety, and consistency review | — |
| architect | System design, module boundaries, ADRs | architect.yaml |
| qa | Test coverage, edge cases, regression prevention | qa.yaml |
| devops | CI/CD, deployment, infrastructure readiness | devops.yaml |
| security | Vulnerability detection, access control, secure coding | security.yaml |

### Commands

```bash
# List available and installed agents
0dai agent-teams --target /path --list

# Show detailed agent definition
0dai agent-teams --target /path --info architect

# JSON output for programmatic use
0dai agent-teams --target /path --json
```

### How It Works

1. Agent definitions live in `templates/layer/ai/templates/claude/agents/*.md.tmpl`
2. Each agent has YAML frontmatter (name, description) and a rich system prompt body
3. Agents are derived from `ai/personas/` — same focus paths, review checklists, and behavioral rules
4. Installed automatically during `init-existing` and `sync` to `.claude/agents/`
5. Matching agents also generated for Gemini CLI (`.gemini/agents/`)

### MCP Tool

`get_agent_teams` returns available agents, installed agents, and persona mappings.

### Python SDK

```python
import zerodayai
teams = zerodayai.agent_teams("/path/to/project")
# {"installed_agents": [...], "personas": [...], "counts": {...}}
```

### Customization

Custom agents can be added to `.claude/agents/` without the `managed: true` marker — they will be preserved during sync. Only managed agents are updated by 0dai.
