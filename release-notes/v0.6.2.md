# v0.6.2

## Team Activity Feed

Unified timeline aggregating all ai/ layer changes across sources.

### Sources

| Source | Data | Entries |
|--------|------|---------|
| audit | CLI operations (init, sync, apply-policy) | audit.jsonl |
| mcp | MCP write mutations (specs, decisions, experience) | wal.jsonl |
| experience | Harvested events (task completions, patterns) | events/*.json |
| git | Commits touching ai/ directory | git log |

### Commands

```bash
# Show activity feed
0dai activity --target /path

# Limit entries
0dai activity --target /path --limit 50

# Filter by source
0dai activity --target /path --filter mcp

# JSON output
0dai activity --target /path --json
```

### MCP Tool

`get_activity_feed` with optional `limit` and `source` filter (33 MCP tools total).
