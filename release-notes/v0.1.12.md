# v0.1.12

This release strengthens the 0dai foundation by turning manifest data into explainable execution policy.

## Highlights

- `ai/manifest/commands.yaml` is now generated as part of bootstrap and sync.
- `0dai doctor` explains environment, execution mode, available CLIs, and command-tier decisions.
- Validation and smoke tests now cover the command policy manifest and doctor diagnostics.

## Major Changes

- command tier manifest with `safe`, `workspace`, and `ops`
- first policy interpreter via `0dai doctor`
- stronger foundation diagnostics for existing repositories

## Validation

- `python3 scripts/validate_templates.py`
- `bash tests/smoke_test.sh`
