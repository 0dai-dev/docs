# v0.5.4

## Observability Templates

Stack-aware tracing configurations for Langfuse, OpenTelemetry, and LangSmith.

### Providers

| Provider | Description | Stacks |
|----------|-------------|--------|
| Langfuse | Open-source LLM observability | All (Python-native) |
| OpenTelemetry | CNCF distributed tracing standard | All |
| LangSmith | LangChain tracing and evaluation | Python stacks |

### Commands

```bash
# List recommendations for your stack
0dai observability --target /path --list

# Generate env template and recommendations
0dai observability --target /path

# Filter by provider
0dai observability --target /path --provider langfuse

# JSON output
0dai observability --target /path --json
```

### Output

- `ai/observability/.env.observability.template` — env vars per provider
- `ai/observability/recommendations.json` — packages, docs, stack mapping

### Stack Coverage

10 stacks mapped: python-service, fastapi, data-ml, django, nextjs, go-service, backend-api, flutter, react-native, fullstack-monorepo.

### MCP Tool

`get_observability` returns stack-aware recommendations with optional provider filter.
