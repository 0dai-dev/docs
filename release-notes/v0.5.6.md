# v0.5.6

## Write-Ahead Log (WAL) for MCP Mutations

All MCP write operations now record file state before mutation, enabling undo/redo.

### Commands

```bash
# List recent WAL entries
0dai wal --target /path --list

# Undo last mutation
0dai wal --target /path --undo

# Undo specific entry
0dai wal --target /path --undo wal-1711700000000

# JSON output
0dai wal --target /path --json
```

### How It Works

1. Before any MCP write (create_spec, record_experience, update_decision), the current file state is recorded
2. WAL entries stored in `ai/manifest/wal.jsonl` with base64-encoded before-state
3. `--undo` restores the file to its pre-mutation state
4. Each entry tracks: action, file path, before/after hashes, size, undo status

### MCP Tools

- `get_wal` — list WAL entries with undo status
- `undo_mutation` — restore a file to its pre-mutation state (31 MCP tools total)
