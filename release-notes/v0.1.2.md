# v0.1.2

This release sharpens the internal architecture of ZeroDayAI so the canonical AI layer and native output layer are more clearly separated.

## Highlights

- Native Codex, Claude Code, and OpenCode files now render from canonical sources in `ai/templates/*`.
- `bootstrap/native_output_map.json` now defines the internal mapping from canonical template sources to emitted native files.
- `templates/root/*` has been reduced to a minimal compatibility bridge instead of acting like a second template source.
- Validation and smoke tests now enforce the cleaned architecture more explicitly.

## Major Changes

- Canonical rendering switched to `ai/templates/*`
- Internal native output mapping layer added
- Compatibility bridge reduced to `.gitignore`, `.mcp.json`, and CI workflow shims

## Validation

- `python3 scripts/validate_templates.py`
- `bash tests/smoke_test.sh`

## Upgrade Note

Projects continue to upgrade through `./bin/ai-repo sync --target <path>`, but the upstream ZeroDayAI internals are now cleaner and more aligned with the canonical `ai/` operating model.
