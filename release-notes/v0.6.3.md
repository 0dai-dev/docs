# v0.6.3

## Role-Based Command Policy

Per-user access control for command tiers in the ai/ layer.

### Roles

| Role | Tiers | Promote | Deploy |
|------|-------|---------|--------|
| viewer | safe | no | no |
| developer | safe, workspace | no | no |
| lead | safe, workspace | yes | no |
| admin | safe, workspace, ops | yes | yes |

### Commands

```bash
# Initialize policy (assigns current user as admin)
0dai role-policy --target /path init

# Assign role
0dai role-policy --target /path set alice lead

# Check access
0dai role-policy --target /path check alice ops

# List assignments
0dai role-policy --target /path list

# JSON output
0dai role-policy --target /path --json
```

### MCP Tool

`get_role_policy` — agents check user permissions before executing ops-tier commands (34 tools total).
