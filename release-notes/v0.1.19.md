# v0.1.19

## Repo Mode Template Packs

Two new template packs provide operating guidance based on repository structure:

### Mono-repo Pack
- Detected by: `workspaces` in package.json, `lerna.json`, `nx.json`, `turbo.json`, `pnpm-workspace.yaml`, or `apps/ + packages/` directories
- Agent guidance: check cross-package imports, prefer shared packages over duplication, use workspace-level commands
- CI strategy: incremental builds, test affected packages only

### Poly-repo Pack
- Detected by: single service structure, no workspaces, standalone dep files
- Agent guidance: self-contained changes, API contracts define boundaries, independent deployment
- CI strategy: full service build/test/deploy on each change

## Repo Mode Detection

`analyze_codebase.py` now automatically classifies repositories:

```json
{
  "repo_mode": "monorepo",
  "entry_points": [...],
  ...
}
```

Detection checks (in priority order):
1. Explicit monorepo config files (lerna.json, nx.json, turbo.json, pnpm-workspace.yaml)
2. Workspaces field in package.json
3. Monorepo directory pattern (2+ of: apps/, packages/, services/)
4. Default: polyrepo
