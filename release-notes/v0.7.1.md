# v0.7.1

## Enterprise Policy Engine + License Gating

### Policy Engine

Centralized org policy management: define once, push to all repos.

```bash
# Initialize policy directory
0dai policy-push --policy-dir /shared/policies init

# Register repos
0dai policy-push --policy-dir /shared/policies add-repo /path/to/repo

# Push policies to all registered repos
0dai policy-push --policy-dir /shared/policies push
```

Default policy includes: protected paths (.env, secrets/, *.pem), denied commands, deployment constraints, and a no-secrets-in-code rule.

### License Gating

Team features now check for `ai/manifest/license.json`:
- `kb` (shared knowledge base)
- `activity` (team activity feed)
- `role-policy` (role-based access)
- `conflicts` (concurrent edit resolution)
- `federation` (cross-repo sync)

Soft gating: shows upgrade message, doesn't crash. Core commands remain fully free.
