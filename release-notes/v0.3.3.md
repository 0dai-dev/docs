# v0.3.3

## MCP Catalog Per Stack

`.mcp.json` is now auto-populated with stack-appropriate MCP servers during `init-existing` and `sync`.

### How It Works

1. 0dai detects your project stack (e.g., fastapi, nextjs, go-service)
2. Looks up recommended MCP servers in `templates/layer/ai/registry/mcp-catalog.json`
3. Merges common + stack-specific servers into your `.mcp.json`
4. Existing servers are never overwritten — only missing ones are added

### Example

For a FastAPI project, `.mcp.json` gets:
- `filesystem` (common — all stacks)
- `python-repl` (stack-specific — Python stacks)

### MCP Tool

`get_mcp_catalog` — agents can query recommended servers for any stack:
```
get_mcp_catalog(stack="fastapi")
→ {common_servers: {filesystem: ...}, stack_servers: {python-repl: ...}}
```

20 MCP tools total.
