# v0.1.9

This release adds the first knowledge-uploader layer on top of the 0dai experience flywheel.

## Highlights

- `scripts/prepare_knowledge_issue.py` prepares a GitHub-native intake summary from the aggregated experience report.
- `knowledge-uploader` in `docker-compose.ai.yml` now runs that intake preparation flow in telemetry mode.
- The runtime now has a clearer bridge from collected experience toward issue or discussion creation.

## Major Changes

- knowledge uploader MVP
- GitHub-native intake summary generation
- telemetry profile aligned with the experience reporting pipeline

## Validation

- `python3 scripts/validate_templates.py`
- `bash tests/smoke_test.sh`
