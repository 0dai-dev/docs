# v0.1.4

This release strengthens 0dai's runtime model and completes the first practical loop for experience promotion.

## Highlights

- Docker runtime now includes a stronger starter pattern with isolated agent mode, tool diagnostics, sample configs, and `.env.ai.example` scaffolding.
- `promote` completes the second stage of the knowledge flywheel by moving reviewed candidates into accepted rules, skills, playbooks, and anti-patterns.
- Validation and smoke tests now cover the expanded runtime and experience lifecycle more explicitly.

## Major Changes

- stronger Docker/devcontainer starter integration
- isolated runner and OpenCode web profile support
- `harvest -> promote` knowledge workflow

## Validation

- `python3 scripts/validate_templates.py`
- `bash tests/smoke_test.sh`
