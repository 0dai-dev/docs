# v0.3.2

## Gemini CLI Support

0dai now supports 4 agent CLIs: **Codex**, **Claude Code**, **OpenCode**, and **Gemini CLI**.

### What's Generated

```
.gemini/
  settings.json     # model, execution, safety settings
  agents/
    coder.md        # default coding agent
    reviewer.md     # code review agent
```

### Detection

`0dai detect` now probes for the `gemini` CLI and `.gemini/` config directory.

### Presets

The `standard` and `enterprise` configure presets now include Gemini:
```bash
0dai configure --target /path --preset standard
# agents: codex, claude, opencode, gemini
```

### Why Gemini CLI

- 96K+ GitHub stars — fastest growing agent CLI
- Free tier: 1000 requests/day
- Apache 2.0 open source
- MCP support built-in
