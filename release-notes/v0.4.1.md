# v0.4.1

## Code Graph Analysis

`ai/manifest/codebase-map.json` now includes an `import_graph` section showing module dependencies.

### What's Analyzed

| Language | Pattern |
|----------|---------|
| Python | `import X`, `from X import Y` |
| JavaScript/TypeScript | `import ... from "X"`, `require("X")` |
| Go | `import "X"`, `import (...)` blocks |

### New Data in codebase-map.json

```json
{
  "import_graph": {
    "files_with_imports": 15,
    "total_import_edges": 47,
    "external_dependencies": {

```

### Use Cases

- Agents understand module coupling before refactoring
- Detect circular dependencies
- Identify most-imported modules (potential abstraction boundaries)
- External dependency ranking shows third-party exposure
