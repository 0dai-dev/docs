# v0.5.1

## Agent Orchestration Config Generator

Generate squad and swarm workspace definitions from your project's ai/ layer.

### Commands

```bash
# Generate orchestration configs
0dai orchestrate --target /path/to/project

# Show team roster
0dai orchestrate --target /path --list

# JSON output for programmatic use
0dai orchestrate --target /path --json
```

### Squad Pattern

Lead agent + specialists + quality gate:

| Role | Agent | Responsibility |
|------|-------|---------------|
| Lead | architect | Design decisions, task delegation |
| Specialist | qa | Test coverage, edge cases |
| Specialist | devops | CI/CD, deployment, infrastructure |
| Gate | security | Final security review before merge |

Includes handoff rules: lead → specialist → gate → lead (on design issues).

### Swarm Pattern

Orchestrator + parallel agents + reviewer:

- Orchestrator (architect) decomposes tasks
- Parallel agents (qa, devops) execute independently
- Reviewer (security) consolidates and validates

Includes task routing patterns (regex-based agent assignment).

### Workflows

Three playbook-derived workflows:
- **bugfix_flow**: reproduce → fix → test → review
- **release_flow**: audit → validate → security → deploy
- **onboarding**: orient → inspect → configure

### Output

Generated to `ai/orchestration/`:
- `squad.yaml` — team structure with lead, specialists, gate
- `swarm.yaml` — parallel execution with orchestrator and routing

### MCP Tool

`get_orchestration` returns both squad and swarm configurations.
