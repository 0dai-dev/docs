# v0.1.18

## Codebase Analysis

A new `analyze_codebase.py` script scans target projects and generates `ai/manifest/codebase-map.json`:

### What It Maps

- **Entry points**: `main.py`, `server.py`, `index.ts`, `main.go`, files in `cmd/`, etc.
- **Dependency managers**: detects `package.json`, `pyproject.toml`, `go.mod`, `Cargo.toml`, `pubspec.yaml`, and 12+ others
- **Directory roles**: classifies top-level dirs (src=source, tests=tests, infra=infrastructure, etc.)
- **File type distribution**: counts by language category
- **Metrics**: total files and directories

### Example Output

```json
{
  "entry_points": ["app/main.py", "cmd/server/main.go"],
  "dependency_managers": {"pyproject.toml": "python", "go.mod": "go"},
  "directory_roles": {"src": "source", "tests": "tests", "docs": "documentation"},
  "file_type_distribution": {"python": 45, "go": 23, "yaml": 8},
  "metrics": {"total_files": 142, "total_directories": 28}
}
```

### Integration

- Runs automatically during `init-existing` and `sync`
- Agents can read `ai/manifest/codebase-map.json` for navigation context
- No external dependencies — uses only Python stdlib
