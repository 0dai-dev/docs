## Community Stack Registry

8 community stacks available out of the box:

| Stack | Description | Tags |
|-------|-------------|------|
| django | Django web framework | python, web |
| rails | Ruby on Rails | ruby, web |
| spring-boot | Spring Boot Java/Kotlin | java, kotlin |
| rust-service | Rust with Cargo | rust |
| svelte-kit | SvelteKit frontend | javascript, web |
| nuxt | Nuxt.js with Vue | javascript, vue |
| terraform | Terraform IaC | infrastructure, devops |
| kubernetes | Helm/Kustomize manifests | kubernetes, devops |

```bash
0dai registry --list                            # browse all
0dai registry --search python                   # filter
0dai registry --install django --target /path   # install to project
```

MCP tool `get_registry` lets agents browse and search stacks.

## IDE Config Generation

Auto-generated during `init-existing` and `sync`:

- **VS Code**: `.vscode/settings.json` (format on save, rulers, excludes) + `.vscode/extensions.json` (stack-specific recommendations)
- **JetBrains**: `.idea/0dai.xml` (run configs for validate, doctor, sync)

Extension recommendations adapt to detected stack (Python tools for FastAPI, ESLint for Next.js, etc.)
