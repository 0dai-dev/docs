# v0.1.5

This release strengthens the container runtime from a basic scaffold into a more practical starter environment.

## Highlights

- Added isolated runner mode for no-network agent execution.
- Added OpenCode web profile support for optional web-based runtime usage.
- Added `0dai-check-tools`, example user and managed configs, and `.env.ai.example` scaffolding.
- Preserved the trusted/untrusted runtime contract while making the Docker layer more useful for daily work and CI.

## Major Changes

- stronger Docker workspace starter integration
- tool diagnostics and sample config scaffolding
- isolated and web runtime profiles

## Validation

- `python3 scripts/validate_templates.py`
- `bash tests/smoke_test.sh`
