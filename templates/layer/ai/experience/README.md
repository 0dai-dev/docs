# Experience Funnel

Use this tree to move observations through a controlled knowledge lifecycle:

`events -> candidates -> accepted/rejected -> archived`

- `events/`: raw session outcomes, logs, and observations
- `candidates/`: proposed lessons waiting for review
- `accepted/`: promoted rules, skills, playbooks, and anti-patterns
- `rejected/`: reviewed but declined candidates
- `archived/`: expired or superseded knowledge
