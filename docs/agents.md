# Supported Agents

0dai generates native configuration for each agent:

## Claude Code
Config: `CLAUDE.md`
Auto-generated project rules, conventions, file structure.

## Codex (OpenAI)
Config: `AGENTS.md`
Project context and instructions for Codex CLI.

## Gemini CLI
Config: `GEMINI.md`
Project-aware configuration for Google's Gemini CLI.

## Aider
Config: `.aider.conf.yml`
Convention settings and project context.

## OpenCode
Config: `opencode.json`
Support for MiniMax and Kimi models.

## Cursor
Config: `.cursorrules`
Editor-specific project rules.

## Windsurf
Config: `.windsurfrules`
Editor-specific project rules.
