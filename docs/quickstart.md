# Quickstart

## Install

```bash
npm install -g @0dai-dev/cli
```

## Initialize

```bash
cd your-project
0dai init
```

The wizard will guide you through agent selection, stack detection, and config generation.

## Verify

```bash
0dai doctor
0dai status
```

## Full onboarding

```bash
0dai quickstart
```

Runs auth check, init, doctor, and status in one command.
